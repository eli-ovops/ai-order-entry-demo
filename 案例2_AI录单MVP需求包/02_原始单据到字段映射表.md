## 明细行字段建议

如果单据中存在多行商品或物料明细，建议将主表和明细表分开。

### 主表字段

| 标准字段名 | 中文名 | 说明 |
| --- | --- | --- |
| document_no | 单据编号 | 一张单据一个编号 |
| document_type | 单据类型 | 采购订单、送货单、报价单等 |
| document_date | 单据日期 | 单据抬头日期 |
| customer_name | 客户名称 | 业务归属方 |
| supplier_name | 供应商名称 | 供应来源方 |
| source_file_name | 原始文件名 | 用于追溯原单 |
| upload_batch_no | 上传批次号 | 用于批量处理和导出 |

### 明细表字段

| 标准字段名 | 中文名 | 说明 |
| --- | --- | --- |
| line_no | 行号 | 系统生成或从原单提取 |
| item_code | 产品编码 | 可选 |
| item_name | 产品名称 | 必填 |
| item_spec | 规格型号 | 建议人工重点校验 |
| unit | 单位 | 必填 |
| quantity | 数量 | 必填 |
| unit_price | 单价 | 可选 |
| amount | 金额 | 可选 |
| remark | 明细备注 | 可选 |

## 识别难度定义

| 难度 | 定义 |
| --- | --- |
| 低 | 字段位置稳定、文字清晰、格式固定 |
| 中 | 字段位置可能变化，但语义清晰 |
| 高 | 字段格式复杂、可能跨行、含手写或印章、容易与其他字段混淆 |

## 错误风险定义

| 风险 | 定义 |
| --- | --- |
| 低 | 错误后主要影响展示或辅助信息 |
| 中 | 错误后影响查询、分类、沟通或内部流转 |
| 高 | 错误后可能影响发货、金额、对账、客户归属或关键业务决策 |
