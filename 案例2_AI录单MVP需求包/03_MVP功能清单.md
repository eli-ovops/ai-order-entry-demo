# 03 L0 Demo 交互功能清单

## MVP 功能范围

当前只定义 L0 Demo 的交互验证范围：上传界面、Mock 识别结果、字段编辑、人工校验提示、记录列表和日志样式展示。以下功能描述不代表已接入真实能力或已完成 MVP 闭环。

## 功能清单

| 模块 | 功能 | 说明 | MVP 必要性 | 验收标准 |
| --- | --- | --- | --- | --- |
| 上传单据 | 文件上传 | 支持上传 PDF、JPG、PNG 等常见单据文件 | 必须 | 用户可以上传单个或多个文件，并看到上传结果 |
| 上传单据 | 批次管理 | 每次上传生成批次号 | 必须 | 每条记录可追溯到上传批次 |
| 上传单据 | 文件基础校验 | 校验文件格式、大小和空文件 | 必须 | 不合规文件有明确提示 |
| OCR 识别 | 文本识别 | 对图片或 PDF 中的文字进行 OCR 提取 | 必须 | 系统能展示 OCR 原文 |
| OCR 识别 | 页面关联 | 保留识别文本与原始文件的关联 | 必须 | 校验时可查看原文件或原图 |
| OCR 识别 | 识别状态 | 展示待识别、识别中、识别成功、识别失败 | 必须 | 每个文件有清晰处理状态 |
| LLM 结构化 | 字段抽取 | 将 OCR 文本转换为标准字段 | 必须 | 能输出客户确认的核心字段 |
| LLM 结构化 | 明细行抽取 | 对表格型单据提取多行明细 | 必须 | 多行商品或物料可按行展示 |
| LLM 结构化 | 置信提示 | 对疑似不确定字段做提示 | 建议 | 低置信或异常字段可标记给人工 |
| 人工校验 | 字段编辑 | 人工可修改结构化字段 | 必须 | 修改后保存的是人工确认结果 |
| 人工校验 | 原单对照 | 校验页面展示原始单据和字段结果 | 必须 | 用户能边看原单边改字段 |
| 人工校验 | 必填校验 | 必填字段为空时阻止保存 | 必须 | 缺少必填字段时有提示 |
| 人工校验 | 规则校验 | 对日期、数字、金额等做基础校验 | 必须 | 格式错误或金额不一致时提示 |
| 保存记录 | 保存确认结果 | 保存人工校验后的结构化数据 | 必须 | 已确认记录可查询、可导出 |
| 保存记录 | 状态流转 | 待校验、已校验、已保存、识别失败 | 必须 | 记录状态清晰可见 |
| 保存记录 | 原始文件关联 | 保存记录关联原始文件信息 | 必须 | 后续可追溯来源文件 |
| Excel 导出 | 按批次导出 | 支持按上传批次导出 Excel | 必须 | 导出的 Excel 包含已确认记录 |
| Excel 导出 | 按时间导出 | 支持按上传时间或保存时间导出 | 建议 | 用户可按日期范围下载 |
| Excel 导出 | 字段顺序配置 | 按客户确认字段顺序输出 | 必须 | Excel 列名和顺序符合客户模板 |
| 基础日志 | 操作日志 | 记录上传、识别、校验、保存、导出操作 | 必须 | 关键操作可追溯到时间和操作人 |
| 基础日志 | 错误日志 | 记录 OCR、LLM、导出等失败原因 | 必须 | 失败记录可定位原因 |
| 基础日志 | 修改记录 | 记录 AI 结果与人工修改差异 | 建议 | 可统计常见识别错误 |

## 核心页面建议

| 页面 | 主要内容 |
| --- | --- |
| 上传页 | 上传文件、选择单据类型、查看上传结果 |
| 批次列表页 | 查看批次、处理状态、成功数、失败数 |
| 校验页 | 左侧原单据，右侧结构化字段和明细表 |
| 记录列表页 | 查看已保存记录、筛选、导出 |
| 日志页 | 查看处理日志、错误原因和导出历史 |

## 核心状态

| 状态 | 含义 |
| --- | --- |
| 待识别 | 文件已上传，尚未进入 OCR |
| 识别中 | OCR 或 LLM 正在处理 |
| 待校验 | 已完成结构化，等待人工确认 |
| 已保存 | 人工校验完成并保存 |
| 识别失败 | OCR 或 LLM 处理失败 |
| 已导出 | 已被包含在某次 Excel 导出中 |

## 后续真实能力验证前置条件

| 验收项 | 验收方式 |
| --- | --- |
| 上传闭环 | 需另行授权并使用客户真实样本上传和生成批次 |
| OCR 可见 | 需接入真实 OCR 后再验证，当前 Demo 仅展示 Mock 结果 |
| 字段结构化 | 需客户确认字段并接入真实处理链路后验证 |
| 人工可改 | 人工修改后保存结果以修改值为准 |
| Excel 可用 | 需生成真实文件并取得客户模板后验证，当前不通过 |
| 日志可查 | 能看到关键操作和失败原因 |
